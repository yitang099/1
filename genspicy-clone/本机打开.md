# 在你电脑上打开（Windows 优先）

Cloud Agent / 隧道里的网站**不会**出现在你电脑的 `localhost` 上。要在本机浏览器里用全功能，请按下面做。

## 最快：双击启动（推荐）

1. 安装 [Node.js LTS 20+](https://nodejs.org/)（一路下一步即可）
2. 用 Git 或 ZIP 下载仓库 [yitang099/1](https://github.com/yitang099/1)，切到分支 `cursor/genspicy-clone-local-10e9`
3. 进入文件夹 **`genspicy-clone`**
4. **双击 `start-windows.bat`**
5. 等黑窗口里出现服务日志，浏览器会自动打开 **http://127.0.0.1:3000**

若仓库在 monorepo 根目录，也可双击根目录的 **`start-genspicy-windows.bat`**。

> 首次运行会自动 `pnpm install`、下载 **ffmpeg**、并 `pnpm build`，可能需要 3–10 分钟，取决于网络。

## 命令行（Mac / Linux / Windows PowerShell）

```bash
cd genspicy-clone
pnpm install
pnpm local
```

`pnpm local` = 安装 + 构建 + 启动 + 自动打开浏览器。

## 自检

浏览器或命令行访问：

```text
http://127.0.0.1:3000/api/health
```

应看到 `"ok": true`，且 `ffmpeg_bundled: true`（表示 Mock 生成能用你的图片出预览视频）。

## 本机能用哪些功能？

| 功能 | 本机 Mock（默认） | 与线上一致（Live） |
|------|-------------------|-------------------|
| 逛模板 / 收藏 / Drama / Tools | ✅ | ✅ |
| 上传图片 + Generate | ✅ 本地 ffmpeg 预览短视频 | 需 `/user/live-account` 填官网 JWT |
| Extend / Like / 创作列表 | ✅ | ✅（Live） |
| 支付 | ❌ 未做 | 走官网 |

**真 GPU 换脸**必须：官网正式账号 Token + Live 模式（Guest Token 官方会 10022）。

## 常见问题

- **Edge 显示「拒绝了连接」** → 没启动服务，请先双击 `start-windows.bat`，窗口不能关。
- **3000 端口被占用** → 黑窗口里先 `Ctrl+C`，再执行：`set PORT=3001` 后改 bat 里 PORT，或用 `PORT=3001 pnpm local`。
- **模板很少** → 可选：`pnpm import:templates`（约 17MB，需联网）；不导入也有 **120 条 sample** 够用。

## 有公网服务器（国内 VPS）

SSH 里粘贴运行仓库内 `scripts/deploy-china-vps.sh`，完成后用脚本输出的 `http://你的IP:8080/` 访问（记得安全组放行端口）。
